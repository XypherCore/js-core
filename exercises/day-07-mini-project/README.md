# Task Manager — JS Mastery Day 7

A CLI-style task manager built in Node.js as a Week 1 capstone project.

## Concepts Demonstrated
- Closure & WeakMap for private state
- Prototype-based OOP (no class keyword)
- Async/await with simulated file I/O
- Auto-save with setInterval
- Priority sorting, overdue detection

## How to Run
node task-manager.js
